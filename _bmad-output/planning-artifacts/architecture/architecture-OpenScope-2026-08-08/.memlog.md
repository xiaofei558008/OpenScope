- (decision) AD-1 模块ABI冻结: OS_Module 结构布局/字段顺序不变，只能追加版本化字段; 防止框架与模块二进制不兼容
- (decision) AD-2 驱动命令通道: 框架仅通过 OS_Module::command(OS_CMD_*) 访问驱动, 不直接触碰 JLink API; 防止框架与具体仿真器耦合
- (decision) AD-3 变量扁平化: ELF 符号表+DWARF 展开为 OS_Leaf 标量叶子(含类型/位域/枚举), 地址在加载时固定; 防止结构体/类型解释在采集路径上重复解析
- (decision) AD-4 采样带时间戳: OS_Sample.ts_us 为 Unix 微秒, 所有读写样本必经环形缓冲分发; 防止绘图/记录失去时间基准
- (decision) AD-5 ELF热加载: 框架轮询 elf 文件 mtime, 变化后弹窗确认→刷新叶子地址→广播 OS_CMD_ELF_RELOADED/on_reload; 防止旧地址读错内存
- (decision) AD-6 依赖方向: 模块→框架回调(OS_Framework), 框架→模块导出(OS_Module), 模块之间禁止直接依赖; 防止循环依赖和模块耦合
- (decision) AD-7 JLink动态绑定: 用 GetProcAddress 绑定 JLink_x64.dll 导出, 不引入导入库; 防止缺少 SDK 时无法构建
- (decision) AD-8 记录格式: CSV 为 v1 默认记录/回放格式, MF4 延后; 防止数据通道设计阻塞采集主线
- (decision) AD-9 构建环境: 统一用 build.py 规范化 PATH 大小写后调 build.bat; git 提交走提权; 防止 MSB6001/沙箱只读导致进度丢失
- (decision) AD-10 叶子id生命周期+重载互斥: id仅单次加载有效, 模块on_reload按名重解析, 重载与采集互斥; 防止旧id错位与悬空访问(对抗评审发现1/4)
- (decision) AD-11 样本所有权与数据约定: ring/OS_Sample框架独占只读分发, raw目标机字节序, ts_us统一os_time_us, 驱动内部互斥序列化读写; 防止多消费者竞态与字节序分歧(对抗评审发现2/3/4)
- (event) spine finalized: lint 0 findings, reviewer gate(adversary+reality) passed, AD-10/AD-11 folded in
