10文件格式

10.1 工程文件 .jscope（XML）

由 FUN_140047020（读）/ FUN_1400471d0（写）确认的层次与属性名。 

<JScopeProject>
  <FileVersion major=".." minor=".."/>
  <Project>
    <Configuration>
      <Connection>
        <TargetInterface/> <InterfaceSpeed/>
        <SerialNo/> <Nickname/>
        <JTAG_IRPre/> <JTAG_DRPre/> <ScriptFile/>
      </Connection>
      <TimeResolutionUs/>  <SamplingPeriod/>
      <IsRTTSession/>  <IsRTTWithTimeStamp/>  <IsRTTPlus/>
      <ElfFile/>  <JLink/>  <Scope/>  <Trigger>
        <Level/> <Auto/> <Rise/> <Fall/>
      </Trigger>
    </Configuration>
    <SelectedSymbols>
      <Symbol>
        <Options Name=".." Type=".." Size=".." Address=".." TypeID=".."
                 GraphColorRed=".." GraphColorGreen=".." GraphColorBlue=".."
                 YMinSampled=".." YMaxSampled=".." YAvgSampled=".."
                 Offset=".." ShowInGraph=".." YOffset=".." IsAutoConfig=".."
                 YResolution=".." MaxValue=".." File=".." DrawStyle=".."
                 NameWithParents=".."/>
      </Symbol>
    </SelectedSymbols>
    <DataFile/>  <RawFile/>  <Timestamp/>
  </Project>
</JScopeProject>

读入时强依赖层次： JScopeProject → FileVersion → Project → Configuration/SelectedSymbols，缺失任一层即失败。

10.2 设置文件

JScopeSettings.ini 段落：DataFiles / ProjectFiles / ELFFiles / LogLevel / Current / PROJECT，键 PATH； MRU 列表格式 %sRecent File List %d\、条目 [%d]: %s。

注册表：Software\SEGGER\%s\（%s = "J-Scope"）。 解析错误串：Error while parsing subkey "%s" in settings file. Syntax error.

10.3 数据导出

支持 .raw（Binary file (*.raw)，另有 Import Raw 反向导入）、 .elf、DataFile。 文件大小上限检查：File too large - maximum file size (%d bytes) exceeded!
