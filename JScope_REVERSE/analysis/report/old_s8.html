TypeID 存于变量记录 +0x314，写入 .jscope 的 TypeID 属性。

TypeID类型树中可选备注

2float64✔

不支持时的 UI 行为：QTreeWidgetItem::setDisabled(true) + 第 4 列文本 "Symbol type is not supported"。

推断 TypeID 3/4 的确切语义未在本轮确证； 结合 demangler 类型表中出现的 half 与 __float128， 推测为 128 位浮点与 16 位浮点。
