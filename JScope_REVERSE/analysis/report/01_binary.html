1.2 导入面：只有 4 个传统 Win32 API

除 Qt 外，J-Scope 只用了极窄的 Win32 面 —— 全部非 Qt 导入如下（这是"该抄什么"的清单）：

对 OpenScope 的启示：J-Scope 把「线程 + 临界区 + 事件 + 高精度计时 + 注册表 + 文件」作为全部 OS 依赖， 其余交给 Qt/CRT。这种"薄 OS 层"让它在 Qt4→Qt5/6 或跨平台移植时改动面极小。OpenScope 的 C11 主线同样应把 OS 依赖收敛到一小组封装（当前 OpenScope 已有 os_* 抽象层，方向一致）。
