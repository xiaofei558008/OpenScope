11命令行接口

命令行走表驱动 + 两阶段解析：静态表 4 项，每项带一个"允许阶段"位掩码； 解析器被调用两次（启动早期 mask=2、初始化完成后 mask=1），从而天然实现了 "-USB/-IP/-RTTSearchRanges 必须在 -openprj 之后生效"的约束。

选项表（RVA 0x74040，0x20 字节/项，FUN_140041cd0 消费；flags 为实测原始值）

struct CmdLineOpt {                  // 4 项，表尾以 name==NULL 结束
    const char *name;               // +0x00
    uint32_t    phaseMask;          // +0x08  与调用方传入的 phase 做 AND，为 0 则跳过
    int       (*handler)(const char *val, size_t len, uint32_t phase);  // +0x10
    const char *help;               // +0x18  ★ 解析器从不读取（本版本为死数据）
};

选项行为（handler 反编译）
-openprj <FILE> 打开 .jscope：解析 XML → 填充配置与符号 → 置"已打开工程"标志 DAT_14285da1e。 参数不以 - 开头时还支持"裸文件名"（以 .jscope 结尾即视为工程） 观测
-USB <SN/昵称> 未先开工程 → "-USB should only be used in combination with -openprj."； 纯数字按序列号（atoi），否则按昵称；解析失败 → "Error while parsing USB S/N"
-IP <host/SN/昵称> 同样要求先开工程（"-IP should only be used in combination with -openprj."）； 把连接类型写成 2（TCP/IP）并填 IP 串
-RTTSearchRanges <A>,<S>[,..] FUN_14003de20：把参数里的 ',' 全部替换成空格（FUN_1400276b0(s, 0x2C, 0x20)）， 再 sprintf(buf, "SetRTTSearchRanges %s", s) 存入 DAT_14285d210（0x200 B）； 真正下发在连接时（§4），语法错误 → "Wrong syntax for \"-RTTSearchRange\".\n"

11.1 解析器细节（FUN_140041cd0）

JLINKARM_ExecCommand("SuppressGUI = 1", 0, 0);        // 解析期间抑制 DLL 弹窗
cmdlineActive = 1;                                 // DAT_14285da1f
for (i = 1; i < argc; i++) {
    arg = argv[i];
    if (arg[0] != '-') {                               // 裸参数：按扩展名猜测
        if (endsWith(arg, ".jscope")) { rc = openProject(arg); continue; }
        break;                                   // 既不认识也不是文件名 → 报未知选项
    }
    for (each opt in table) {
        if ((opt.phaseMask & phase) == 0) continue;      // 阶段不匹配 → 跳过（值也一并跳过）
        if (matchPrefix(arg, opt.name) == 0) {          // 前缀匹配
            val = nextArgOrInline(arg + nameLen);
            rc = opt.handler(val, len, phase);
            if (rc < 0 || cmdlineError) goto fail;
            if (rc == 1) return 1;                        // 请求结束启动流程
            break;
        }
    }
    if (未匹配) log("CMDLINE: Unknown command line option \"%s\" detected!", arg);
}
JLINKARM_ExecCommand("SuppressGUI = 0", 0, 0);
cmdlineActive = 0;

三个可观察的行为特征：

① argv[0] 之后任何不以 - 开头且不以 .jscope 结尾的参数都会报未知选项； ② 选项匹配是前缀匹配（FUN_1400277f0），因此 -USBxxx 这种粘写形式也能识别； ③ 表里的 help 文本没有任何代码读取——它是给某个已移除的"命令行帮助"功能留的，本版本不可达。

另外 FUN_14003cc50 用 argc < 2 判断是否显示 WelcomeDialog： 带任何命令行参数启动都会跳过欢迎框，直接进主窗口。
