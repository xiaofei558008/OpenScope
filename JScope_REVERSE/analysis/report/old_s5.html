05HSS 高速采样协议（异步）

5.1 变量描述符数组

FUN_140041f30 构造并下发给探针。

// 每个变量 16 字节；末尾追加一个 {addr=0,size=0} 终止项
struct HssVar {          // 16 bytes
    uint32_t addr;       // +0x00  变量绝对地址
    uint32_t size;       // +0x04  字节数
    uint32_t reserved0;  // +0x08  = 0
    uint32_t reserved1;  // +0x0C  = 0
};

uint32_t n = 0;
HssVar *list = malloc((n + 1) * 16);   // +1 给终止项
memset(list, 0, (n+1) * 16);

uint32_t off = 4;                    // ★ 从 4 开始：前 4 字节是时间戳
for (每个被选中的变量 v) {
    v->sampleOffset = off;           // 记在 v+0x38C
    off += v->size;                  // v+0x31C
    list[i].addr = v->addr;          // v+0x318
    list[i].size = v->size;
    /* 同时复位统计量：
       v->yMaxSampled(+0x398) = -DBL_MAX   (0xFFEFFFFFFFFFFFFF)
       v->yMinSampled(+0x3A0) = +DBL_MAX   (0x7FEFFFFFFFFFFFFF)
       v->writePtr(+0x3C8) = v->dataBuf(+0x3D0) = 0   */
}
list[n].size = 0;                    // 终止项

rc = JLINK_HSS_Start(list, n, samplingPeriod_us /*config+0x5A8*/, 1 /*flags*/);

返回码（错误串逐字来自二进制）

rc含义
-2Failed to allocate memory on debug probe
-3Too many variables specified
-4Target hardware does not support HSS
其它 <0Failed to inititalize HSS. （原文拼写错误 inititalize）

启动成功后立即让目标跑起来：

if (JLINK_IsHalted()) JLINK_Go();

5.2 采样包格式

JLINK_HSS_Read(buf, size) 返回本次读到的字节数， 缓冲区内容为紧密排列的定长样本。变量在样本内的偏移在 JLINK_HSS_Start 之前就固定算好，读取后直接按偏移切片。

实例：3 个变量 g_speed(float32) · g_state(uint8) · g_count(int16) → 样本 = 4+4+1+2 = 11 字节

offset 0timestampuint32 · µs
offset 4g_speedfloat32 · 4 B
offset 8g_stateuint8 · 1 B
offset 9g_countint16 · 2 B
ts (µs) g_speed g_state g_count → 样本按此长度首尾相接填满整个读缓冲

5.3 读取泵

FUN_140040fa0

int bufSize = 0x200000 - (0x200000 % (sampleSize * numVars));  // ≈2 MB 对齐
void *buf = malloc(bufSize);
int n = JLINK_HSS_Read(buf, bufSize);      // 返回字节数
if (n >= 0) UnpackSamples(n, buf);
free(buf);

由 10 ms 周期 Job（APP: <ReadPeriodic>，job->period = 10）驱动 —— 探针在后台以设定周期自主采样并缓存，主机每 10 ms 批量取走积压数据。 采样率与主机轮询频率彻底解耦，这正是 HSS 能到 µs 级的原因。
