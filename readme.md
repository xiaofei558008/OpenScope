# OpenScope 软件用户说明书

**适用于 Windows | 版权所有**

---

## 1. 软件简介

OpenScope 是一款专为嵌入式开发设计的高性能调试与数据采集工具。其核心功能与 Vector VX1000/CANape 类似，通过标准调试接口（SWD/JTAG）实现对目标MCU内存变量的非侵入式读取、可视化监控与标定。

### 设计理念

- **高性能**：采用 C 语言开发，确保极速响应与最小系统资源占用。
- **模块化**：基于插件（.dll）架构，所有功能窗口（波形、数值等）均为独立模块，支持无限扩展。
- **智能化**：集成 BMAD 自动化流程管理，全程无需人工干预指令执行。

## 2. 快速开始

### 2.1 安装与启动

1. 运行安装包 `OpenScope_Setup.exe`，按照提示完成安装。
2. 首次启动后，软件将自动加载 `dll` 文件夹下的所有功能插件。
3. 主界面布局将自动恢复为上次关闭时的状态；**上次加载的 `.elf`/`.out` 文件也会自动加载**，直接回到上次的调试现场（文件已删除/移动时仅提示警告，不弹窗打扰）。
4. **随时按 `F1` 键**（或菜单“帮助 → 帮助文档”）即可打开本说明书；再次按 `F1` 或 `Esc` 关闭。

### 2.2 连接目标MCU

1. **硬件连接**：通过 J-Link 仿真器连接 PC 与目标开发板。
2. **配置连接参数**（主界面顶部工具栏）：
   - **仿真接口**：选择 `SWD` 或 `JTAG`。
   - **时钟速度 (kHz)**：在下拉菜单中选择或手动输入（支持如 4000, 6000, 12000 等）。**注意**：速度过高可能导致连接失败，请从较低速度开始尝试。
   - **J-Link 设备**：点击“刷新”按钮列出所有已连接的 J-Link，并从下拉列表中选择一个。
3. **连接**：点击 **“连接”** 按钮。成功连接后，状态栏将显示“已连接”。

### 2.3 加载变量定义文件

1. 点击 **“加载 ELF”** 按钮，选择编译生成的 `.elf` 或 `.out` 文件（下一次启动会自动加载它，无需重新选择）。
2. 软件将自动解析文件中的**全局变量**和**结构体**，并展现在左侧 **“变量浏览器”** 中。
3. **动态更新**：若您在调试过程中重新编译了工程，软件将自动检测到 `.elf` 文件更新，并弹窗提示您重新加载，刷新变量地址。若变量找不到，会询问您是否忽略。

## 3. 核心功能详解

### 3.1 变量管理与视图

- **隐藏与展开变量栏**（三种方式）：
  - **拖拽隐藏**：鼠标拽着变量栏右侧分隔线**一直往左拉**（低于 60px），变量栏完全隐藏，仅剩左侧细条。
  - **双击隐藏**：双击竖向分隔线，在隐藏/展开之间切换。
  - **展开恢复**：点击左侧细条展开；或从细条处把分隔线向右拖出（宽度跟随拖拽位置）。
- **钉住与自动隐藏**：变量浏览器右上角的“图钉”图标控制窗口是否固定。
  - **钉住**（金色，默认）：隐藏后保持隐藏，**悬停细条不会误弹出**，必须显式点击细条展开。
  - **自动隐藏**（灰色）：鼠标移开窗口自动向左侧边界隐藏（抽屉式缩起）；隐藏后悬停细条自动展开，方便快捷浏览。
- **变量选择**：
  - **多选**：按住 `Ctrl` 键并单击，可逐个选择变量。
  - **范围选择**：点击起始变量，按住 `Shift` 键再点击结束变量，将选择两者之间的全部变量。
  - **全选**：在变量列表区域按 `Ctrl+A`。
- **右键添加**：在选中的变量上右键，可快速添加到波形窗口或数值窗口。
- **快速搜索**：按 `Ctrl+F` 打开“搜索变量”对话框（模糊搜索，实时过滤）。在下方列表选中变量后**右键**，可“添加到波形窗口”或“添加到数值窗口”（对话框保持打开，可连续添加）；点“确定”则在左侧变量树中定位选中的变量（自动展开祖先并滚动到可见）。

### 3.2 波形窗口

- **添加窗口**：在任意标签（Tab）内，通过右键菜单选择“新建波形窗口”。
- **添加变量**：在波形窗口内右键，弹出“添加变量”对话框。支持模糊搜索，并可使用上述 `Ctrl/Shift` 快捷键多选变量。
- **缩放与导航**：
  - **滚轮缩放**：在波形区域滚动鼠标滚轮，缩放 X 轴（时间）；`Ctrl+滚轮` 缩放 Y 轴（数值）。缩放平滑连续，围绕鼠标位置。
  - **框选放大**：在波形区域按住鼠标左键拖拽框选，局部放大所选区域（松开前可见亮青选框）。
  - **拖拽平移**：`Ctrl+左键拖拽` 平移视图（限制在数据范围内）。
  - **X 轴滚动条**：缩放后底部自动出现水平滚动条，拖拽滑块快速平移时间窗到想观察的点（全局显示时自动隐藏）。
  - **全局显示**：按 `F` 键，将当前所有波形完整适配到窗口区域。
  - **多坐标轴**：按 `Ctrl+B` 键，将每个信号独立显示在一行（拥有独立Y轴），再次按下则恢复为共轴显示。坐标轴颜色与波形线颜色一致。
- **数据光标与测量**：
  - 点击波形上的采样点，将悬浮显示该点的（变量名、值、数据类型）。
  - 拖动光标线（垂直/水平），可在信息栏查看 ΔX（时间差）与 ΔY（数值差）。
- **采样点显示**：波形放大到一定程度后，每个采集点将以**圆点**形式清晰标示，方便观察采样间隔。
- **录制与回放**：
  - **自动落盘**：开始采集即自动建立记录（RAM 缓冲 ≤10MB，超出写 `%LOCALAPPDATA%\OpenScope\records\rec_年月日_时分秒.csv`，文件名按时间命名避免重复）。长时间采集不再占用大量内存，采集停止时数据已完整落盘。
  - 点击 **“录制”** 按钮，可额外将数据保存到自选 `.csv` 文件（可选）。
  - 点击 **“离线回放”**，选择记录的 CSV（自动落盘文件或手动录制文件），**全部数据一次性加载并整体显示到波形窗口**（min/max 桶包络渲染，缩放/平移任意时间区间，放大后显示采样圆点）。

### 3.3 数值窗口

- **实时监控与标定**：在数值窗口可添加变量列表。每个变量前有复选框：
  - **勾选**：变量值随采集实时更新。
  - **取消勾选**：变量值冻结，方便观察特定时刻数据。
- **数值修改**：直接在变量对应的“值”列双击或选中后按 `Enter`，输入新值即可完成标定写入，无需弹窗。
- **最小值/最大值列**：每个变量附带“最小值”“最大值”两列，记录运行过程中该变量的极值：
  - 随采集实时更新（首个样本初始化，之后逐样本取极值）；取消“实时”勾选时同步冻结。
  - **支持手工修改**：双击最小值/最大值单元格直接输入（`Enter` 提交，调试用，不写入设备）。手工值作为新的跟踪起点——之后低于它的样本继续扩展最小值、高于它的继续扩展最大值（典型用法：清掉启动瞬态尖峰后重新跟踪）。
  - ELF 重新加载后自动重置（地址可能已变化，历史极值作废）。

### 3.4 标签（Tab）管理

- **新建标签**：在标签栏空白处右键，选择“新建波形标签”或“新建数值标签”。
- **重命名**：在标签上**双击**，直接输入新名称；若清空所有字符，则自动恢复为默认名称 “Default”。
- **窗口管理**：一个标签内可同时容纳多个波形/数值窗口，每个窗口支持最大化、最小化及鼠标拖拽调整大小。
  - **列宽拖拽**：鼠标悬停两个平铺窗口之间的分隔带（光标变为 ⇔），按住左键拖拽即可调整列宽比例。
  - **最小化**：标签右键菜单选择“最小化当前窗口”，窗口折叠进标签页底部的最小化条；点击最小化条上的窗口标题按钮即可还原。

### 3.5 消息窗口

- 支持 `Ctrl/Shift` 多选消息。
- 右键菜单支持复制所选消息、清除全部消息。
- 窗口顶部/底部边缘支持鼠标拖拽调整高度，方便查看历史记录。

### 3.6 界面风格

- 通过 **“设置”** 菜单，可在 **“白色（默认）”** 与 **“黑色（IAR/Notepad++风格）”** 两种主题间切换，缓解视觉疲劳。

## 4. 性能优化说明

### 采样速度提升

针对早期版本固定 20ms 采样间隔的问题，已进行以下优化：

1. **移除固定延时**：采集线程不再使用 `Sleep(20ms)`，改为“读完立即下一周期”。
2. **批量块读取**：将多个连续地址的变量合并为一次 USB 读取事务，大幅减少通信开销；合并距离随 SWD/JTAG 时钟**速度自适应**（时钟越高合并越积极）。
3. **UI刷新限频**：数据采集与界面渲染分离，UI 仅以 30~60Hz 刷新，避免消息队列阻塞。
4. **时钟速度**：支持手工输入，预置档位最高 **50MHz**（J-Link Pro 的 SWD/JTAG 上限）。
5. **长时间采集自动落盘**：采集数据缓存在 RAM（≤10MB），超出自动写入按时间命名的 CSV 文件，长时间运行不再占用大量内存；采集停止即完整落盘。

**预期性能**：
- 单变量轮询可达 **5~10kHz**。
- 多变量（地址连续）同样可达 **3~10kHz**。
- 分散变量可提高到 ~20k 样本/s（速度感知块读合并，日志中“次读/周期”显示合并效果）。
- 如需 µs 级采样，建议使用片上缓冲（XCP风格），将在后续版本支持。

### 常见问题

**Q：连接时提示“未发现J-Link设备”怎么办？**

A：请检查：
- J-Link 仿真器是否正确连接 PC 并已供电。
- 驱动是否已正确安装（驱动目录：`C:\Program Files\SEGGER\JLink_V966`）。
- 点击工具栏“刷新”按钮重新扫描设备。

**Q：为什么部分速度下采集到的变量值都是0？**

A：请尝试使用 4000 kHz 或更低速度连接。部分高速设置（如 12000 kHz）可能因通信不稳定导致读取失败，建议从较低速度逐步上调。

**Q：波形窗口添加多个变量后，软件闪退怎么办？**

A：该问题已在当前版本修复。如仍出现，请检查：
- 是否加载了正确的 `.elf` 文件，变量地址是否有效。
- 内存占用是否过高，尝试减少同时观测的变量数量。

**Q：如何实现更高速的采样？**

A：当前版本已优化轮询机制，单变量可达 5~10kHz。如需 µs 级采样，后续版本将支持片上缓冲（XCP风格）方案。
